IMPORTANT - LICENSING
----------------------
Do NOT add copyrighted recordings you do not have permission to use.

Only add audio that is one of the following:
  - Public domain (for example, many official U.S. military bugle call
    recordings are in the public domain).
  - Recorded by you or your unit specifically for this project.
  - Licensed for redistribution, with permission clearly documented.

If a file is missing, the web page will automatically show the message
"Audio recording not yet available." instead of a broken audio player, so
it is safe to publish this site before all recordings are ready.
