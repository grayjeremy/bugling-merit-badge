IMAGES (SHEET MUSIC)
=====================

Place sheet music images in this folder using exactly these file names
(the web page looks for these names automatically, matching the audio
file base names):

  first-call.png
  reveille.png
  assembly.png
  mess.png
  drill.png
  fatigue.png
  officers.png
  recall.png
  church.png
  swimming.png
  fire.png
  retreat.png
  to-the-colors.png
  call-to-quarters.png
  taps.png

Each bugle call card has a "View Sheet Music" link that opens the matching
image in a new browser tab so a Scout can practice reading it. If an image
is missing, the page automatically shows "Sheet music not yet available."
instead of a broken link, so it is safe to publish this site before all
images are ready.

IMPORTANT - LICENSING
----------------------
Do NOT add copyrighted sheet music you do not have permission to use.

Only add sheet music that is one of the following:
  - Public domain (for example, many official U.S. military bugle call
    sheet music transcriptions are in the public domain).
  - Created by you or your unit specifically for this project.
  - Licensed for redistribution, with permission clearly documented.

You may also add a small logo or icon image here if you'd like; the site
does not require any images to function, as the header currently uses a
simple original SVG bugle icon drawn directly in index.html.
